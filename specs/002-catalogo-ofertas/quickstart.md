# Quickstart: Catálogo

Con 001 operativo, abrir catálogo visitante y filtrar hasta vacío; limpiar.
Elegir proveedor, guardar oferta válida, enviar a moderación. Elegir admin y aprobar con
motivo; comprobar ficha pública. Contratar en 003, luego cambiar precio/suspender;
comprobar que snapshot previo no cambia. Intentar edición vieja y autoaprobación: rechazo.
Ejecutar npm test y npm run build raíz; verificar 375/1440 px y errores por campo.
