# Contratos Soroban (pendientes)

Ubicación para una prueba de viabilidad de cuenta contractual y reglas de autorización por trabajo. Antes de afirmar control on-chain hay que integrar y verificar autorización, token SEP-41, firma, SDK y facilitator x402. No hay contrato ni despliegue.

Especificación y alternativas: [pagos](../docs/payments-and-budget.md). Versiones observadas: [herramientas](../docs/toolchain-and-sources.md). Si se autoriza la prueba, utilizaría Cargo/Rust separado de las aplicaciones; hoy contiene solo este documento. No crear un vault genérico ni atribuirle garantías sobre un `transfer` que no controla.
